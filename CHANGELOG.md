# Changelog

All notable changes to the MINT License Suite are recorded here.

## 1.0 — Initial release

- Base license `MINT`.
- Modules: `CODE`, `SOFTWARE`, `PUBLIC`, `DESIGN`, `DATA`.
- License texts in `en-US` and `zh-CN`.
- Human-readable summaries in `en-US` and `zh-CN`.
- JSON Schema for `MINT-COMPONENTS.toml` and `MINT-OFFICIAL-API`.
- Templates for both structured files.

### Known limitations

- License texts are available in two languages only. Additional translations may be added in later minor versions without changing obligations.
- GitHub's license detector will label this repository "Other". This is expected; see `licenses/LICENSE`.
