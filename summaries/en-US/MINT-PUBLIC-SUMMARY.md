# MINT PUBLIC Module — Summary

> This is a human-readable summary of the MINT PUBLIC module.
> It is **not** a license. The authoritative text is `licenses/en-US/LICENSE-MINT-PUBLIC`.

## You can

- **Access the Work through an Official API** without the CODE module's reciprocity obligation applying to that access.
- **Build independent implementations** of the API without triggering copyleft.

## You must

- **Use only the Official API.** If you access the Work through any other path, or if no valid Official API exists, the CODE module applies in full.

## You cannot

- **Claim supersession after touching source.** If you copy, modify, or distribute the Source Code, the supersession lapses.
- **Embed source in a modified wrapper.** If you modify the Official API wrapper and embed or copy the Source Code into it, the supersession lapses.
- **Rel y on an invalid designation.** If the designation file is unreachable, schema-invalid, or lists interfaces the Work does not provide, no Official API exists.

## How supersession works

When you access the Work solely through an Official API, and do not copy, modify, or distribute the Source Code, the CODE module's reciprocity obligation does not apply to that access. This is a **behavior-level** supersession, not a file-level one.

## Invalid designation

An invalid designation cuts the supersession entirely. The CODE module continues to apply. The risk of an invalid designation lies with the copyright holder; a recipient need only make a reasonable attempt to access the stated location.
