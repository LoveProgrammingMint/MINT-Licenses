## You can

- **Use and modify** Source Code files of the Work.
- **Distribute** the Work alongside proprietary files that are not derived from it.
- **Access the Work through an Official API** without triggering the reciprocity obligation, if the PUBLIC module is also applied.

## You must

- **License modified files under this module.** If you modify any file of the Work, the modified file must be licensed under MINT + CODE.
- **Make modified files available** to recipients under this module's terms.
- **Include the license texts and notices** when you distribute the Work or a Modified Version.

## You cannot

- **Absorb or replace obligations.** If other MINT modules apply to the same distribution, their obligations are cumulative, not substitutable.

## Per-file scope

The reciprocity obligation applies **per file**. Files not derived from the Work, distributed alongside it, are not affected.

## Official API designation

The copyright holder may designate an Official API by publishing a `MINT-OFFICIAL-API` file. The file may be in this repository, another repository, or at a stable URL. If the designation is invalid — unreachable, schema-invalid, or listing interfaces the Work does not provide — then no Official API exists for the PUBLIC module, and this module continues to apply in full.
