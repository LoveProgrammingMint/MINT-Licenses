## You can

- **Use, modify, and integrate** design elements — icons, layouts, themes, visual specifications — into your products.
- **Distribute** products containing those design elements, for any purpose, including commercially.
- **Choose the notice location** — About screen, documentation, or a license file.

## You must

- **Provide a notice on integration.** When you integrate design elements into an interactive product and distribute it, make available a notice that identifies the design elements used, the Licensor, and the MINT modules applied.
- **Respect parallel obligations.** If the product also includes CODE or SOFTWARE components, their obligations apply alongside this one.

## You cannot

- **Use brand elements.** Logos, product names, and other brand identifiers are expressly excluded from the copyright grant.
- **Absorb or replace module obligations.** This module does not replace the SOFTWARE notice obligation or the CODE reciprocity obligation.

## Scope

This module applies to visual design elements. It does not apply to Source Code or to the functional logic of an interface. If a file contains both design and code, split the obligations by component mapping.

The license grants no rights to trade names, trademarks, service marks, or product names. Brand elements require separate permission from the Licensor.
