# MINT 代码模块 — 摘要

> 本文件是 MINT 代码模块的人类可读摘要。
> 它**不是**许可证。权威文本为 `licenses/zh-CN/LICENSE-MINT-CODE`。

## 您可以

- **使用和修改**本作品的源代码文件。
- **分发**本作品，并与并非源自本作品的专有文件并存。
- **通过官方 API 访问本作品**而不触发回馈义务（若同时适用 PUBLIC 模块）。

## 您必须

- **修改文件须以本模块授权。** 若您修改了本作品的任何文件，修改文件须按 MINT + CODE 授权。
- **使修改文件可获取**，按本模块条款向接收者提供。
- **附上协议文本与声明**，在分发本作品或修改版本时。

## 您不能

- **吸收或替代义务。** 若同一分发中其他 MINT 模块适用，其义务累加，不可相互替代。

## 按文件适用

回馈义务**按文件逐一**适用。并非源自本作品、但与本作品一并分发的文件，不受影响。

## 官方 API 指定

版权持有人可通过发布 `MINT-OFFICIAL-API` 文件指定官方 API。文件可位于本仓库、其他仓库或稳定 URL。若指定无效——不可达、不符合 schema、或所列接口并非本作品实际提供——则就 PUBLIC 模块而言不存在官方 API，本模块继续完全适用。
