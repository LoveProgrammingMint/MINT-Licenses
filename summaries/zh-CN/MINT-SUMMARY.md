# MINT 许可证 — 摘要

> 本文件是 MINT 许可证基础条款的人类可读摘要。
> 它**不是**许可证，不授予也不限制任何权利。
> 权威文本为 `licenses/zh-CN/LICENSE-MINT`。

## 您可以

- **使用**本作品，用于任何目的，包括商业用途。
- **修改**本作品并创作修改版本。
- **分发**本作品及修改版本。
- **组合**其他 MINT 模块，以许可方声明为准。

## 您必须

- **保留声明。** 在本作品及修改版本的所有副本中保留著作权、专利、商标和免责声明。
- **标明来源。** 说明本作品来源于许可方并根据 MINT 许可证授权。
- **回授专利许可。** 若您提交贡献，您的贡献按相同条款授权。

## 您不能

- **使用商标。** 本许可证不授予使用许可方名称、徽标或产品名称的权利。
- **要求许可方担责。** 本作品按“现状”提供，不附带担保。
- **一边起诉一边保留许可。** 若您就本作品对贡献者提起专利侵权诉讼，您的专利许可终止。

## 模块

基础条款本身不施加回馈、声明或同协议共享义务。这些义务来自模块：

| 模块 | 增加 |
|---|---|
| CODE | 文件级回馈 |
| SOFTWARE | 产品分发声明 |
| PUBLIC | API 访问取代 |
| DESIGN | 设计整合声明 + 商标排除 |
| DATA | 衍生数据集同协议共享 |

作品可声明任意组合，例如 `MINT + CODE + PUBLIC`。

## 终止

若您违反本许可证，您的权利终止。若您在收到通知后 30 日内纠正违约，权利恢复。
