# MINT 设计模块 — 摘要

> 本文件是 MINT 设计模块的人类可读摘要。
> 它**不是**许可证。权威文本为 `licenses/zh-CN/LICENSE-MINT-DESIGN`。

## 您可以

- **使用、修改和整合**设计元素——图标、布局、主题、视觉规范——到您的产品中。
- **分发**包含这些设计元素的产品，用于任何目的，包括商业用途。
- **选择声明位置**——关于界面、文档或协议文件。

## 您必须

- **整合时提供声明。** 将设计元素整合进交互式产品并分发时，向接收者提供声明，标明所使用的设计元素、许可方以及所适用的 MINT 模块。
- **遵守并行义务。** 若产品同时包含 CODE 或 SOFTWARE 组件，其义务与本模块并行适用。

## 您不能

- **使用品牌元素。** 徽标、产品名称及其他品牌标识明确排除在著作权授权之外。
- **吸收或替代模块义务。** 本模块不替代 SOFTWARE 的声明义务或 CODE 的回馈义务。

## 适用范围

本模块适用于视觉设计元素，不适用于源代码或界面的功能逻辑。若同一文件既含设计又含代码，按组件映射拆分义务。

## 商标排除

本许可证不授予商号、商标、服务标志或产品名称的任何权利。品牌元素须另行取得许可方授权。
