# MINT 公开接口模块 — 摘要

> 本文件是 MINT 公开接口模块的人类可读摘要。
> 它**不是**许可证。权威文本为 `licenses/zh-CN/LICENSE-MINT-PUBLIC`。

## 您可以

- **通过官方 API 访问本作品**，该访问行为不触发 CODE 模块的回馈义务。
- **独立实现**该 API，而不触发 Copyleft。

## 您必须

- **仅使用官方 API。** 若您通过其他路径访问本作品，或不存在有效的官方 API，CODE 模块完全适用。

## 您不能

- **接触源码后仍主张取代。** 若您复制、修改或分发源代码，取代失效。
- **在修改后的封装中嵌入源码。** 若您修改官方 API 封装并将源代码嵌入或复制其中，取代失效。
- **依赖无效指定。** 若指定文件不可达、不符合 schema、或所列接口并非本作品实际提供，则不存在官方 API。

## 取代如何成立

当您仅通过官方 API 访问本作品，且未复制、修改或分发源代码时，CODE 模块的回馈义务不适用于该访问行为。这是**行为级**取代，不是文件级取代。

## 指定无效

指定无效会完全切断取代，CODE 模块继续适用。指定无效的风险由版权持有人承担；接收方仅需合理尝试访问所述位置。
