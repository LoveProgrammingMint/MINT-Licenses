# MINT 产品模块 — 摘要

> 本文件是 MINT 产品模块的人类可读摘要。
> 它**不是**许可证。权威文本为 `licenses/zh-CN/LICENSE-MINT-SOFTWARE`。

## 您可以

- **分发**包含本作品的产品，用于任何目的，包括商业用途。
- **保持专有模块为专有**，前提是该模块并非源自本作品。
- **选择声明位置**——关于界面、文档或协议文件。

## 您必须

- **分发时提供声明。** 分发包含本作品的产品时，向接收者提供声明，标明所适用的 MINT 模块并包含免责声明。
- **遵守各模块义务。** 若产品同时包含 CODE、DESIGN 或 DATA 组件，其义务并行适用。

## 您不能

- **吸收或替代模块义务。** 本模块不替代 CODE 的文件级回馈、DESIGN 的声明义务或 DATA 的同协议共享。
- **把产品当作单一协议作品。** 包含多个 MINT 组件的产品，其义务累加。

## 适用范围

本模块适用于将产品作为整体分发。不适用于组织内部使用。

## 不传染

并非源自本作品的专有模块，不因与本作品一并分发而单独受 MINT 约束。
