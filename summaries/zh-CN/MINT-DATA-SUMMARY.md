# MINT 数据模块 — 摘要

> 本文件是 MINT 数据模块的人类可读摘要。
> 它**不是**许可证。权威文本为 `licenses/zh-CN/LICENSE-MINT-DATA`。

## 您可以

- **使用、分析和转换**数据，包括商业用途。
- **分发**本作品及衍生数据集，前提是遵守同协议共享条款。
- **将本作品与独立数据集组合**，前提是本作品未被修改。

## 您必须

- **提供来源声明。** 标明许可方及所适用的 MINT 模块；保留附于本作品的所有声明。
- **衍生数据集同协议共享。** 若您创建衍生数据集并分发，须以本模块授权。

## 您不能

- **主张对个人数据的权利。** 本模块不授予对个人数据的任何权利。
- **借提取输出规避同协议共享。** 若您的输出是对本作品的实质性提取，同协议共享义务适用。

## 同协议共享的例外

同协议共享义务不适用于：
- 使用软件处理本作品所产生的输出，且该输出并非对本作品的实质性提取。
- 将本作品与独立数据集一并纳入的集合，且本作品未被修改。

## 结构与内容

数据库结构可在声明时按 CODE 或 DESIGN 授权。本模块管辖数据内容本身。两者同时适用时，义务累加。

## 个人数据

若本作品包含个人数据，您有责任取得适用法律要求的任何额外法律依据。
